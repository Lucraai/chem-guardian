# 架构说明

## 目标

构建一个支持私有化部署的化工安全标准顾问 Agent 平台。

## 分层

### 1. 业务主系统

- 用户与权限
- 租户与项目
- 文档管理
- 标准管理
- 票证管理
- 整改管理
- 审计日志

### 2. AI 服务

- 文档解析
- OCR
- 条款切分
- 向量检索
- RAG 回答生成
- 场景分析

### 3. 检索层

- Qdrant
- 支持条款、场景、术语、票证字段检索

### 4. 数据层

- PostgreSQL：业务数据
- Redis：缓存和会话
- MinIO：文件与附件

## 数据流

1. 用户上传标准文档或票证
2. 业务系统保存原始文件并记录元数据
3. AI 服务解析文档并切分条款
4. 条款写入向量库和业务数据库
5. 用户提问时先检索相关条款
6. 生成带来源的回答
7. 结果写入审计日志

## 原则

- 所有回答必须可追溯
- 高风险结论必须人工确认
- 核心能力自研，避免依赖不可控平台
